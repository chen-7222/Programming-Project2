大一時候製作第二份專題，新的遊戲，玩法更簡單易懂，也把第一份製作時的一些缺點改了。
我所製作的遊戲為數字瞬時記憶力挑戰，主要考驗玩家的記憶力以及心算能力。遊戲玩法很簡單，記下出現過的所有數字並將它們全數相加並輸入你得到的答案。
遊戲流程介紹
遊戲首頁
 
在進入開始畫面以後，會出現上圖的遊戲畫面，右方為排行榜，使用下方程式碼載入排行榜

下方可選擇難易度(預設簡單)，分別為簡單以及困難模式，簡單模式為10個數字，數字範圍1-20，數字每次出現1秒。困難模式也為10個數字，數字範圍1-30，數字每次出現0.8秒。在按下開始按鈕後會將難度和使用者姓名傳遞到表單:遊戲畫面中。(放在遊戲畫面的程式碼中)，並在按下(遊戲畫面的)開始按鈕後讀取資訊並根據難易度做變更。




左上方為存取排行榜檔案功能，讓玩家能夠將排行榜儲存並下載。使用saveFileDialog控制項做儲存檔案的動作，(下圖為檔案名稱)儲存檔案使用txt檔，在儲存成功後會跳出Messagebox告訴玩家儲存檔案成功，若此時排行榜並無資料，則會顯示儲存失敗。



在輸入名字後(必須輸入，沒有輸入會跳出訊息提醒)，按下開始按鈕即可開啟遊戲。並將難度和使用者姓名傳遞到表單:遊戲畫面中。
 
遊戲畫面1
 

進入遊戲後，並不會直接開始遊戲，而是會出現上圖，左上方為提示，而在按下開始按鈕之前無法做任何動作。
 
按下開始按鈕後則會換成下圖畫面
遊戲畫面2
 
在按下開始按鈕後，畫面會依序出現10組數字(在此期間無法做任何事情)，根據一開始所選擇的難易度題目會有所不同。
 

此為數字依序出現所使用之程式碼，在10組數字全數出現後，標籤就會變更為:請輸入答案，而左上方的標籤也會變更為提示等等的作答時間。
 
在數字全數出現以後，畫面會變成下方圖片
遊戲畫面3
 
這時畫面中間會提示玩家可以開始輸入答案在下方textbox中，並且左上方的倒數計時也會開始。
在按下確認答案按鈕後，會將計時停止，若是此時textbox裡面沒有任何東西，則會提示請輸入答案。

使用CheckAnswer驗證玩家輸入的答案是否正確，並根據答題結果更新排行榜，時間計算則是使用DateTime.Now獲取當前時間，減去遊戲開始時記錄的startTime，得到TimeSpan物件表示答題所用時間，並調用SaveRankingEntry保存成績。(所使用時間越少成績越好)
